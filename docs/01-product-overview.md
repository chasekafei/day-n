# 产品概览与用户流程

## 1. 产品定位

“乒乓历”是一个乒乓球球迷日期工具。用户可以选择王楚钦、孙颖莎、莎头或自定义关注对象，再从事件库中选择入坑节点，查看从那一天到今天经过了多少天，并生成一张可分享的日期卡。

后续产品扩展为通用的日期关系工具：

- 从某个事件到今天经过了多少天
- 某个事件距离指定日期还有多少天
- 两个事件之间相隔多少天
- 两个重要事件之间是否出现 511、1104、365 等特殊数字

产品不使用“成为乒乓妹”作为对外名称，也不依赖 CP、排行或拉踩叙事。卡片表达的是日期、记忆和球迷自己的经历。

## 2. 功能入口

首版首页提供四个对象选项：

- 王楚钦
- 孙颖莎
- 莎头
- 自定义

选择对象后，事件列表只展示相关事件。自定义对象允许用户填写自己的称呼和日期；如果没有对应的结构化成就数据，只展示日期计算和事件记录，不虚构个人冠军统计。

首版功能入口建议为：

1. **入坑日**：从入坑日计算到今天。
2. **事件之间**：计算两个事件的间隔。
3. **指定日期**：计算事件距离指定日期的天数。
4. **日期探秘**：检查两个日期之间是否命中特殊数字。

## 3. 首版用户流程

```text
打开工具
  └─ 首页：乒乓历 / 记录重要日期
       ├─ 选择对象
       ├─ 选择热门事件
       ├─ 按年份、类型或关键词筛选更多事件
       ├─ 自定义完整日期
       └─ 只知道年份，按年份生成“约”日期
  └─ 确认日期口径
       ├─ 默认：起始日算第 1 天
       └─ 高级选项：起始日算第 0 天
  └─ 结果页
       ├─ 显示天数、入坑事件、称号和统计
       ├─ 切换卡片模板
       ├─ 保存到相册
       ├─ 发布图文
       └─ 带图评论
```

已经有本地存档时，首页直接显示“今天是入坑第 N 天”，同时提供“重新选择”。存档丢失时不能阻塞用户重新制作。

## 4. 结果卡内容

信息层级固定为：

1. 最大数字：`入坑第 N 天` 或 `相隔 N 天`
2. 主称号：如“千日见证者”“巴黎见证者”
3. 起始事件和日期
4. 见证统计：只显示当前对象适用的统计口径
5. 下一个里程碑或特殊日期倒计时
6. 生成日期、数据截至日期、乒乓历标识

默认规则是起始日算第 1 天。第 0 天模式放在高级设置中，避免第一次使用时增加理解成本。

## 5. 语言和合规边界

- 不在卡片中使用真人照片、肖像、WTT 或 ITTF Logo。
- 真名只在事件事实描述中出现，称号使用赛事、日期和乒乓术语。
- 不做粉丝等级排行、谁更资深、谁更配对等内容。
- “缘分”只通过日期间隔和特殊数字呈现，不把日期计算包装成事实性关系判断。
- 统计口径和数据截至日期必须在说明页公开。
