# 卡片设计与分享

## 1. 设计原则

视觉重点是“日期数字”和“事件记忆”，不是工具说明。

建议色彩：

- 奶油白：`#FFFBF0`
- 薯条金：`#F5C842`
- 深棕红：`#B5451B`
- 深棕：`#3D2B1F`
- 赛事蓝、比分红作为辅助色

不使用真人照片、运动员肖像、WTT/ITTF Logo或复杂的写实人物插画。

## 2. 首版模板

### 票根 Ticket

作为默认模板。左侧突出“第 N 天”，右侧显示起始事件、日期和短统计，底部使用条形码、撕口和编号等装饰。默认适合笔记分享。

### 记分牌 Scoreboard

深色底、点阵数字和红蓝比分感。评论版优先使用这套，要求在 120×120 缩略图中依然能看出天数。

### 日历撕页 Calendar

突出年月、日期和“入坑第 N 天”，适合生日、周年和纪念节点。

### 球台 Table

用球台中线分隔起始日期和目标日期，适合事件间隔和“从某场到某场”的卡片。

## 3. 生图和模板流程

必须先生成设计稿，再实现代码：

1. 为每个模板生成 2–3 个设计方向。
2. 先确认整体排版、比例和信息层级。
3. 使用参考图生成“无示例文字”的干净背景。
4. Canvas 只绘制可变日期、数字、称号和统计。
5. 通过像素坐标把变量填入设计稿预留区域。
6. 导出前检查示例文字、白色遮罩、透明底和裁切。

不能再让 Canvas 从零绘制完整插画，也不能用 `contain` 缩放把内容缩到卡片中央。模板需要使用明确的屏幕/字段槽位，并用裁剪或固定比例填充。

## 4. 输出规格

- 评论卡：1080×1080
- 笔记卡默认：1080×1440
- 后续可增加：1080×1920
- 生成后的图片必须是不透明背景
- 设计稿可以保存在 `docs/design/`
- 生产包只放压缩后的 WebP/PNG 素材

## 5. 分享语义

评论卡只突出日期卡本身，默认评论文案可以是：

> 我入坑第 N 天，你是哪场入坑的？

笔记卡可以带少量引导文案：

> 今天是我入坑第 N 天。你还记得自己是哪场比赛开始喜欢上他们的吗？

评论图片和评论文字分开处理，不能把工具介绍硬塞进卡片。发布图文、带图评论和保存图片都要提供独立的失败提示和降级路径。
