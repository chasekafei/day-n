# 乒乓历

乒乓历是一个离线运行的小红书小工具，用来记录入坑日、计算事件间隔，并生成日期纪念卡。

## 已实现

- 王楚钦、孙颖莎、莎头、自定义四种关注对象
- 186 条本地事件数据筛选
- 按年份、类型和关键词搜索事件
- 入坑第 N 天计算
- 自定义日期和备注
- 两个事件之间的日期差值
- 特殊数字检测基础能力
- 票根、记分牌、日历、球台四种卡片样式
- 本地存档和继续上次记录
- 保存图片、发布图文、带图评论的平台桥接
- 离线发布检查和压缩打包

## 本地开发

```bash
pnpm install
pnpm dev
```

## 验证和打包

```bash
pnpm test
pnpm check
pnpm build
pnpm package
```
